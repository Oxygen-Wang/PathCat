径猫 · PathCat

完整的中英文说明、版本号和功能介绍见 README.md。
版本管理流程见 VERSIONING.md，变更记录见 CHANGELOG.md。

双击 启动PathCat.bat，或运行 python PathCat.py。
可执行版本请使用 GitHub Releases 的版本化 ZIP。
点击小猫或 Shift+Z 打开文件侧栏，拖入文件夹可打开路径。
拖到路径标签可移动，悬停切换后可继续拖入子目录；Ctrl 拖动复制，Esc 取消。
右键小猫可调整配色、字体大小、语言、快捷键及重播教学。
小猫默认置顶；5 分钟无交互后睡觉，Shift+Z 或点击小猫可唤醒。
必要的猫咪图片和界面图标随源码及发行包提供。
旧 QuietPet 设置目录保留兼容，Codex 插件及信息工具适配已删除；侧栏本地 Skills 标签可复制引用、拖出 SKILL.md。

当前版本：0.2.0-beta.6（测试版）。
小猫和面板默认置顶；切换软件收起面板，悬停展开不抢键盘焦点。
点击放大镜或 Ctrl+F 展开搜索；面板收起时清空搜索。
右键可切换默认/三花猫及四档大小；拖面板边缘保存宽度。
教学仅从右键菜单手动打开，启动不自动显示。
